# M0 qualification evidence

This directory contains the cold-start attestation, pinned-artifact identity,
SLSA source relationship, real-runtime qualification outputs, test results, and
retained failed-attempt records for M0. It contains no market data and no
research result.

The official wheel itself is deliberately not vendored. It was downloaded to
`/tmp`, verified before installation, and installed only into the ignored
project-local `.venv`.
